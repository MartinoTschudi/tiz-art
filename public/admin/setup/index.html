Accesso per Tiziana

Questa pagina è per Martino. Crea (o rinnova) l’accesso dell’admin:

  1. scegli l’e-mail e la password con cui Tiziana entrerà;
  2. incolla un token GitHub «fine-grained» solo per il repository del sito, con i permessi Contents: Read and write e Actions: Read;
  3. tocca «Configura»: la chiave viene cifrata qui nel browser e salvata nel repository (public/admin/auth.json) con lo stesso token.

Meglio una frase di 4 parole, facile da scrivere sul telefono e usata solo qui.

github.com → Settings → Developer settings → Fine-grained tokens. Non viene mai salvato in chiaro.
